# 하루 — 통합 개인 대시보드

클로드 버전의 첨부 화면에서 한 줄 기록, 이번 주 한 걸음, 역할별 목표, 챙길 일, 영역별 요약 구성을 참고하고 기존 하루 시안의 관계·건강·투자·대출 기능을 통합한 로컬 웹 버전입니다. 첨부 화면만 검토했으며 클로드 버전의 소스나 내부 동작을 검토한 것은 아닙니다. 기존 `/workspace/ceo-diary`, `/workspace/lifelog-preview` 파일과 데이터는 변경하지 않습니다.

## 실행

Python 3가 있는 환경에서 이 폴더를 작업 디렉터리로 사용합니다.

```bash
python3 -m http.server 8020 --bind 127.0.0.1
```

브라우저에서 해당 로컬 서버를 엽니다. `index.html`, `styles.css`, `app.js`가 같은 폴더에 있어야 합니다. 별도 빌드나 패키지 설치는 없습니다. 다른 작업 세션에서는 서버를 다시 시작해야 합니다. 환경은 이미 격리되어 있으므로 별도 Git worktree를 만들 필요가 없습니다.

## 처음 사용할 때

1. 홈의 **예시로 둘러보기**를 선택하면 별도 데모 공간에서 기능을 눌러볼 수 있습니다. 데모의 금액·건강·관계·목표는 모두 가상이며 사용자 사실이 아닙니다. 상단 링크로 내 기록 화면에 돌아옵니다.
2. 실제 기록 화면에는 사용자께서 알려준 투자 회사(이사), 워크스워크, PWR과 가족·관계, 나 자신 역할만 기본 등록되어 있습니다. 금액과 건강 수치는 비어 있습니다.
3. 목표·꿈에서 원하는 결과와 이유, 장애물, 실행 계획을 적습니다. 목표를 열어 준비 단계를 추가합니다.
4. 홈에서 할 일 하나를 이번 주 한 걸음으로 지정합니다.
5. 주간 점검과 중요한 결정의 예상·실제 결과를 남깁니다. 분기·연간 점검도 기간별 보관합니다.
6. **백업**으로 JSON 파일을 보관합니다. 복원은 현재 형식의 파일을 확인한 뒤 명시적으로 현재 기록을 교체합니다.

## 실제 동작

- 자유 기록·검색·역할 연결
- 활동 추가·수정·삭제, 본업·사이드프로젝트·부업·개인사업·삶 구분
- 목표·버킷리스트, 역할 연결, 준비 단계·할 일·완료 체크
- 역할별 목표, 이번 주 집중 행동, 날짜가 있는 할 일·관계 이슈·대출 납부·결정 점검 모아보기
- 건강 선택 기록, 같은 날짜 갱신, 기록한 날 기준 7일 수면 평균·활동 일수
- 투자 스냅샷, 대출 조건·잔액 기준일·다음 납부일·만기
- 관계별 순간·시간, 월간·주간 시간 합계, 이슈·다음 행동·완료
- 중요한 결정·예상 결과·실제 결과·강점, 실제 시간 사용 관찰
- 오늘 하루 일기: 날짜별 작성·수정, 자유 본문과 선택 질문, 과거 날짜 작성
- 홈에서 오늘 일기 이어쓰기와 최근 7일 작성일 표시. 미작성일은 실패로 평가하지 않음
- 일기는 저장 버튼을 누를 때 보관되며 자동 임시저장은 제공하지 않음
- 매일·주간·분기·연간 점검 이력
- 홈에 최근 저장한 돌아보기 3개 표시: 성과·장애물·다음 행동·줄일 일 미리보기, 기간별 원문 바로 열기
- 지난 주간 점검의 다음 행동을 홈과 주간 점검에 표시. 할 일로 한 번만 복사하고 완료 상태 연결
- 같은 기간의 수정은 홈에도 반영. 할 일로 복사한 행동은 원문을 보존하며 이후 문구 편집은 서로 독립적
- 실제 저장 시각을 새 기록부터 보관. 저장 시각이 없는 기존 기록도 기간을 기준으로 표시
- JSON 백업·복원. 관계나 목표 삭제 시 연결만 해제하고 관련 기록은 보존

단계 완료율은 등록된 할 일의 완료 비율이며 목표 전체의 객관적 달성률이 아닙니다. 관계 시간은 직접 기록한 구간만 집계하며 관계의 질을 평가하지 않습니다. 활동 계획 시간과 실제 사용 시간은 서로 다른 값입니다.

## 참고한 방법

핵심은 방법을 많이 넣는 것이 아니라 드러커의 강점·시간·기여·피드백과 코비의 역할별 주간 계획을 실제 행동으로 연결하는 것입니다. 각 방법의 성격과 원 출처는 화면의 **설계 근거** 및 `SOURCES.md`에 있습니다. 분기·연간 질문과 UI 자체는 이 서비스의 응용입니다.

## 저장과 범위

현재는 브라우저 localStorage 저장입니다. 사용자 로그인, 서버 저장, 저장 데이터 암호화, 기기 간 동기화, Google Calendar, 금융 자동 연동, 자동 알림, 사진 첨부는 포함되지 않았습니다. 도메인·포트·브라우저를 바꾸면 같은 저장소를 사용하지 않습니다. 개발 서버를 외부에 공개하면 로그인 보호가 생기는 것이 아니므로, 개인 자료를 입력할 때 접근 환경을 확인해야 합니다.

실제 기록 키는 `haru-integrated-v1`, `?demo=1` 공간은 `haru-integrated-demo-v1`입니다. 데모는 별도 저장되며 실제 기록을 덮어쓰지 않습니다. 중요한 자료는 백업하고 공용 기기에 민감한 금융·의료·타인의 개인정보를 입력하지 마세요. 외부 폰트는 jsDelivr에서 로드하며, 접근이 안 되면 시스템 글꼴로 표시됩니다.

## 검증

이 클라우드 인스턴스의 Chromium / Playwright로 다음을 검증했습니다.

- 한 줄 기록·검색, 목표→할 일→이번 주 행동 연결과 완료 토글
- 투자·대출·수입 입력, 건강 동일 날짜 갱신, 관계 시간 합산·이슈 완료
- 활동 추가·필터, 주간·분기 점검과 결정 노트 저장 후 새로고침 복원
- JSON 다운로드 및 동일 파일 복원
- 390px 모바일에서 8개 주요 화면과 설계 근거 화면 가로 넘침 없음
- 브라우저 페이지 오류 없음

이 검증은 현재 로컬 인스턴스의 동작 증거이며 서버 배포·다중 사용자 인증·외부 연동·새 환경 복원에 대한 검증은 아닙니다. 스크린샷은 가상 데이터가 있는 데모 화면입니다.

## 성찰 일기와 생활 리듬 업데이트

- 일기 기본 흐름: 장면과 감정 → 발견한 점 → 다음 시도. 첫 장면만 필수이며 분석·교훈을 강요하지 않습니다.
- 깁스의 성찰 순환을 축약한 제품 응용입니다. 이 3문항 조합 자체의 효과가 검증된 것으로 소개하지 않습니다.
- 감사 기록과 CBT 생각 기록을 참고한 사실·해석·대안 질문은 선택 영역입니다. 기존 일기 필드는 그대로 보존합니다.
- 일기에 남긴 발견과 다음 시도는 해당 주의 돌아보기에서 원문 그대로 모아볼 수 있습니다. 다음 시도를 할 일로 한 번만 가져올 수 있습니다.
- 운동 여부·활동 시간·음주 여부는 건강에 보관합니다. 별도 습관 탭은 추가하지 않았습니다. 기존 활동 시간만 있는 기록은 운동했다고 추정하지 않습니다.
- 주간 돌아보기의 ‘이번 주 흐름’은 일기 작성일·운동일·음주일·기록 시간만 간단히 집계합니다. 시간 배분·관계 시간·수면은 펼쳐서 봅니다.
- 모든 비율·평균은 기록한 범위를 기준으로 하며, 미기록을 실패나 낭비로 해석하지 않습니다. 관계 시간과 시간 기록은 겹칠 수 있어 합산하지 않습니다.

## 전체 현황 홈 업데이트

- 홈 상단에 업무 할 일 완료/전체, 목표 준비 단계 완료/전체, 이번 주 기록 시간, 이번 주 일기 작성일을 집계합니다.
- 업무·목표 수치는 등록된 현재 기록 전체를 기준으로 합니다. 작업 완료 시각 이력이 없으므로 주간 업무 성과로 표시하지 않습니다.
- 업무별 완료 현황·연결 목표·다음 행동과 실제 기록 시간의 역할별 비중을 홈에서 볼 수 있습니다.
- 업무·목표·시간·일기 요약 카드를 누르면 해당 상세 화면으로 이동합니다.
- 건강·관계·투자·대출·회고도 같은 홈에서 요약하며, 소비·수입 입력을 요구하지 않습니다.
- 등록된 준비 단계 완료율은 목표 자체의 객관적 달성률이 아닙니다. 시간 비중은 기록 구간만 기준입니다.
- 홈 집계, 체크 후 갱신, 시간 추가 후 갱신, 새로고침 복원, 상세 이동, 390px 모바일 화면을 검증했습니다.
